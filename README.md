# Borough Park Rules Website

A responsive, blue-themed FiveM roleplay rules website starter.

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub account and a new **public** repository (example: `borough-park-rules`).
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your address will look like:
   `https://YOUR-USERNAME.github.io/borough-park-rules/`

## Customize before publishing
Search all files for:
- `https://discord.gg/boroughpark` and replace it with your real Discord invite.
- `Borough Park` to change branding if needed.
- The last-updated date.
- Any rules or procedures you want to publish.

## Important
This starter is a design and content scaffold, not an official policy document. Review and replace example language with Borough Park's approved rules, definitions, evidence standards, and punishment schedule before launch. Add your actual rule sections and contact links.
